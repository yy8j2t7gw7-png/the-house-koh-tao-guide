# Places Database v1.0

The platform now uses a unified places model for restaurants, cafés, bars, beaches, viewpoints, shopping, medical services, transport, activities and wellness.

## Core fields
`id`, `type`, `status`, `featured`, `displayOrder`, `name`, `shortName`, `area`, `categories`, `tags`

## Editorial fields
`about`, `recommendation`, `localTip`, `perfectFor`, `aiSummary`, `aiKeywords`

## Media
`logo`, `heroImage`, `gallery`

## Menu types
`none`, `images`, `pdf`, `website`, `multiple`

Guests always see one simple action label: `Menu`.

## Actions
`showMenu`, `showCall`, `showMap`, `showWebsite`, `showBooking`

## Editorial rules
No rankings, scores, ratings or negative reviews. Every included place must have a clear reason for recommendation.
